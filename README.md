# Respira Lab

Учебная станция для разбора дыхательной недостаточности у взрослых. Слева генератор синтетического случая и его показатели, в центре оценки и статьи PubMed, справа агент DeepSeek с ходом выполнения. Внизу можно открыть пакеты JSON-RPC для любого вызова.

## Быстрый запуск без Docker

Распакуйте ZIP и откройте терминал в папке `respira-lab`, рядом с `run_local.py`. Нужны Python 3.12 и интернет для установки зависимостей, PubMed и RouterAI. В ZIP интерфейс уже собран, поэтому для запуска достаточно Python.

**macOS и Linux**

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run_local.py
```

**Windows PowerShell**

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run_local.py
```

Когда в терминале запустится Uvicorn, откройте [Respira Lab](http://127.0.0.1:8512/). Скрипт запускает веб-приложение и SSE в одном терминале. Оба процесса останавливаются по Ctrl+C. Если порты заняты, добавьте к команде запуска `--web-port 8513 --sse-port 8003` и откройте [порт 8513](http://127.0.0.1:8513/).

Если рядом с `run_local.py` уже есть `.env`, приложение прочитает его автоматически. В копии из Git создайте `.env` из `.env.example` и задайте `ROUTERAI_API_KEY`. В Finder скрытые файлы видны по Cmd+Shift+точка. Ключ используется для чата и обработки свободного описания случая. Расчеты, поиск по готовым сценариям и ручной поиск PubMed доступны без ключа. Держите ZIP с заполненным `.env` в приватном доступе: вызовы агента расходуют баланс владельца ключа.

## Запуск в Docker

Откройте Docker Desktop или запустите Docker Engine. В папке проекта выполните:

```sh
docker compose up --build
```

Откройте [Respira Lab](http://127.0.0.1:8512/). Остановить приложение можно командой `docker compose down`. SSE доступен с хоста на `http://127.0.0.1:8002/sse`. Порты Docker можно изменить в `RESPIRA_WEB_PORT` и `RESPIRA_SSE_PORT` в `.env`. После обновления ключа перезапустите веб-контейнер командой `docker compose up -d --force-recreate web`.

## Сборка интерфейса из исходников

Для сборки из Git или после изменений в интерфейсе нужен Node.js 22.12+:

```sh
npm --prefix frontend ci
npm --prefix frontend run build
```

После сборки запустите `run_local.py` по инструкции выше.

## MCP-архитектура

| Источник | Транспорт | Инструменты |
|---|---|---|
| stdio | Дочерний Python-процесс `python -m respira.server`, официальный MCP SDK 2.x | PaO₂/FiO₂, CURB-65, qSOFA, `list_calculators` |
| SSE | Async MCP-клиент, Starlette и Uvicorn, `GET /sse`, `POST /messages?session_id=…`; SDK также принимает `/messages/` | Те же три шкалы, NEWS2, ROX, `list_calculators` |
| Внешний [PubMed MCP](https://glama.ai/mcp/servers/cyanheads/pubmed-mcp-server) | HTTPS Streamable HTTP | Поиск публикаций и получение аннотаций по PMID |

FastAPI — хост и маршрутизатор. В Vue-форме выбор источника и поиск основаны на `tools/list`. Поля строятся из `inputSchema`. Все расчеты и запросы проходят через `tools/call`. Инспектор сопоставляет реальные запросы и ответы по JSON-RPC `id`. Сетевой клиент переводит числа и флаги в ожидаемые типы. Когда явно включен учебный режим, он также подставляет только пропущенные поля из синтетического случая и перечисляет их в результате. Пользовательские значения сохраняются. SSE повторяет подключение при временном отказе. Внешний обмен ограничен 12 секундами, успешные запросы кэшируются на 10 минут.

Агент использует `deepseek/deepseek-v4-flash` через RouterAI, получает описания MCP-инструментов от приложения и выбирает вызовы. RouterAI выбирает совместимого провайдера этой модели по цене. В чат передаются описание, результаты расчетов по текущим значениям и актуальная подборка статей. Описание для подбора обрабатывает RouterAI. PubMed MCP получает сформированный поисковый запрос. Используйте синтетические данные. Значения и категории предназначены для демонстрации методик.

## Сценарий защиты

1. Нажмите «Рассчитать показатели». PaO₂/FiO₂ из stdio дает 200 мм рт. ст.; NEWS2 из SSE дает 7. Раскройте разбор NEWS2, сравните вклады компонентов и откройте методику.
2. Откройте вкладку «Инструменты». Выберите SSE → NEWS2. На пустой форме включите Smart Defaults и нажмите «Выполнить». Интерфейс укажет, какие поля подставил сетевой клиент. Для проверки ошибки выключите Smart Defaults и введите SpO₂ 110.
3. Введите описание синтетического случая и нажмите «Подобрать статьи». Модель выделит заболевание и тему поиска. PubMed вернет публикации с PMID. Нажмите заголовок, чтобы открыть аннотацию.
4. Спросите в чате «О чем вторая статья и какой вывод сделали авторы?». Агент получит аннотацию по PMID и разберет ее.
5. В журнале «MCP-вызовы» видны расчеты, подбор статей и обращения агента. Нажмите значок кода рядом с вызовом, чтобы открыть его в инспекторе JSON-RPC. Кэшированные ответы помечаются отдельно.
6. Нажмите «Новый случай». Откроется другой синтетический пример, а чат, подборка и журнал очистятся.

Для подключения к Cursor предусмотрен `.cursor/mcp.json`. Создайте локальную `.venv` и запустите приложение с SSE на порту 8002. Конфигурация рассчитана на macOS/Linux и SSE-порт 8002.

## Контрольные вопросы

1. **MCP, REST и OpenAPI.** REST описывает взаимодействие с ресурсами сервиса. OpenAPI документирует этот HTTP-интерфейс. MCP дает агенту единый протокол для обнаружения инструментов, чтения параметров и вызовов поверх разных транспортов.
2. **Логи stdio.** stdout зарезервирован для кадров JSON-RPC, поэтому логи направляются в stderr.
3. **JSON-RPC.** Запрос содержит `jsonrpc`, `id`, `method` и `params`. Для `initialize` в параметрах идут версия протокола, возможности и сведения о клиенте, для `tools/call` — `name` и `arguments`. Ответ содержит тот же `id` и `result` или `error`.
4. **Масштабирование.** stdio использует выделенный процесс и каналы ОС. SSE допускает несколько клиентов у одного сетевого процесса, но требует обработки таймаутов и отказов соединения.
5. **Входные данные.** Хост проверяет схему, сервер перепроверяет типы и границы, формулу выполняет детерминированный инструмент. Пропущенные измерения требуют уточнения. Синтетические значения разрешены только в явно указанном учебном режиме.
